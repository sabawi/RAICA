How It Works: The 7-Stage Deployment Pipeline

1️⃣

Requirement Analysis (AI-Powered)

Simply describe your website in plain English. The AI analyzes your description and extracts structured requirements including features, authentication needs, database entities, and business logic.

2️⃣

Architecture Design (AI-Generated)

AI architect designs a complete technical architecture: RESTful API endpoints, database schema with relationships, background workers, security configuration, and infrastructure components.

3️⃣

Code Generation (Production-Ready)

Generates complete FastAPI application with authentication, database models, API endpoints, Pydantic schemas, CRUD operations, background workers, and frontend templates.

4️⃣

File Transfer (Secure SSH)

Securely transfers all generated files to your remote server using SSH/SFTP with automatic directory creation and permission management.

5️⃣

System Configuration (Automated)

Automatically installs Python, PostgreSQL, Redis, and your choice of Nginx or Apache2. Creates virtual environment, installs dependencies, and configures database with automatic user creation.

6️⃣

Web Server Setup (Nginx or Apache2)

Configures reverse proxy, static file serving, WebSocket support, security headers, SSL certificates with Let's Encrypt, and creates systemd services for auto-start.

7️⃣

Launch & Verify (Production Ready)

Starts all services, runs health checks, verifies deployment, and provides you with the live URL. Your website is now accessible to the world with HTTPS!

Example: Deploy a Blog in 5 Minutes

Step 1: Write Your Idea (Plain English)

"Build a simple blog platform where users can:
 - Register and log in with email/password
 - Create and publish blog posts with titles and content
 - View all published posts in reverse chronological order
 - Comment on posts
 - Each post shows author name and publish date
 - Simple, clean interface with responsive design"

Step 2: Provide Server Credentials

export DEPLOYMENT_SSH_HOST="your-server-ip"
export DEPLOYMENT_SSH_USER="ubuntu"
export DEPLOYMENT_SSH_KEY_PATH="~/.ssh/your-key.pem"

Step 3: Run the Deployment

python examples/full_deployment_demo.py

Getting Started

Prerequisites:

# 1. Fresh Ubuntu/Debian server (cloud or on-premises)
# 2. SSH access with key-based authentication
# 3. Sudo privileges on the server
# 4. Python 3.12+ on your local machine

Installation:

# Clone the repository
git clone https://github.com/yourusername/website-deployer.git
cd website-deployer

# Install dependencies
pip install -r requirements.txt

# Configure LLM provider (choose one or enable all)
# Edit config/llm_config.yaml with your API keys

Configure Server Access:

# Set environment variables
export DEPLOYMENT_SSH_HOST="your.server.ip"
export DEPLOYMENT_SSH_USER="ubuntu"
export DEPLOYMENT_SSH_KEY_PATH="~/.ssh/your-key.pem"

# Optional: Domain for SSL
export DEPLOYMENT_DOMAIN="yourdomain.com"

Deploy Your First Website:

# Run the full deployment pipeline
python examples/full_deployment_demo.py

# Follow the prompts:
# 1. Describe your website idea in plain English
# 2. Confirm deployment when ready
# 3. Wait 5-10 minutes
# 4. Your website is live! 🎉
